# 🚀 AI Career Copilot Resume

An AI-powered career assistant designed to help job seekers optimize their resumes, improve ATS compatibility, and prepare for job opportunities with intelligent recommendations.

## 📌 Features

* 🔍 Resume Analysis
* 📄 ATS Score Evaluation
* 🧠 Skill Extraction
* 🎯 Job Description Matching
* 📊 Resume Improvement Suggestions
* 🚨 Missing Skills Detection
* 🏆 Resume Ranking
* 💼 Career Guidance
* 🎤 Interview Preparation Recommendations
* 🔐 Secure User Authentication

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/Ashutosh2444/Ai-Career-Copilot-Resume.git
cd Ai-Career-Copilot-Resume
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Environment Variables

Create a `.env` file:

```env
GOOGLE_API_KEY=your_api_key_here
```

### 6. Run Application

```bash
python app.py
```

Application will start on:

```text
http://127.0.0.1:5000
```
